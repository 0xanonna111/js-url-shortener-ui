# js-url-shortener-ui 🔗

A frontend UI for a URL shortener application built using JavaScript.

## ✨ Features
- URL input & validation
- Mock short URL generation
- Copy to clipboard
- Clean & professional UI

## 🛠 Technologies
- HTML
- CSS
- JavaScript

## 🚀 Note
This is a UI-only project. Backend or API can be integrated later.
